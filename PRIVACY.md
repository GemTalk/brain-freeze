# Privacy

The Ice Cream Brain Freeze README ends with a tracking pixel from Scarf. If you would rather not be counted, you deserve to know exactly what it does.

## What the pixel does

The pixel is an invisible image at the bottom of the README. When your browser loads the README, it also asks Scarf for that image. GemTalk uses the requests to count README views and to see which kinds of organizations are curious about the demo, so we know whether it is reaching the people it was built for.

## What Scarf collects

For each request, Scarf looks up business details about the network address that made it, such as the company, the general location, and the cloud provider. Scarf states that it does not store the IP address and that it purges personally identifiable information immediately after the lookup. GemTalk sees only the resulting summary in our Scarf account, never your address.

Scarf explains this in its own words:

- [How does the tracking pixel work?](https://docs.scarf.sh/faq/#how-does-the-tracking-pixel-work)
- [Data privacy and security](https://docs.scarf.sh/faq/#data-privacy-security)

## How GemTalk uses it

We use the counts to understand interest in the demo. We do not use them for advertising.

## If you would rather not be counted

A browser setting or an ad blocker that blocks remote images will stop the request. The README reads the same without the pixel.
