# Privacy

The README ends with a Scarf tracking pixel, an invisible image that loads when you view it.

**What we collect:** Scarf looks up business details for the requesting network address, such as company, general location, and cloud provider. Scarf states that it does not store IP addresses and purges personally identifiable information right after the lookup. GemDB only sees aggregate summaries, never your address.

**Why:** We use the counts to see how many people view the demo and what kinds of organizations are interested. We do not use them for advertising.

**Opting out:** Block remote images in your browser or with an ad blocker. The README reads the same without the pixel.

Learn more from Scarf: [How the pixel works](https://docs.scarf.sh/faq/#how-does-the-tracking-pixel-work) · [Data privacy and security](https://docs.scarf.sh/faq/#data-privacy-security)
